# Integración resuelta — MVP reducido

La conexión a PostgreSQL ya funciona. Migraciones y carga mínima aplicadas.

Por indicación del usuario, esta versión muestra solo ocho piezas compatibles,
una por categoría. No se cargó el catálogo amplio y se pausaron las ampliaciones
de administración/carga en lote que estaban en preparación.

Funciona: catálogo, configurador, guardado privado y borrador PDF sin precios
inventados. La emisión comercial exige cotizaciones verificadas.

Ver [ESTADO-INTEGRACION.md](./ESTADO-INTEGRACION.md) para probar el recorrido.
