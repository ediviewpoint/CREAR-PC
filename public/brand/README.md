# CREAR PC / Marca
Direcciones: wordmark tipográfico, monograma C.PC y case isométrico.
Principal: wordmark; sello: monograma; favicon: isométrico.
Cada dirección incluye SVG y PNG transparente 1x/2x/3x, navy, navy profundo
monocromo y blanco inverso. SVG geométricos a stroke 1.5.
El favicon SVG cambia blanco/navy según prefers-color-scheme; PNG e ICO
incluyen fondo blanco opaco para legibilidad. No estirar ni agregar efectos.
Zona de protección: altura de una letra. Wordmark mínimo 20 px de alto;
usar marca icónica en 16/32/48 px.
Regenerar: node scripts/generate-brand.mjs.
