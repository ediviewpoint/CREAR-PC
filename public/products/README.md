Una foto principal por producto basta para esta versión. Recomendación: al menos 1000×750 px, fondo blanco y producto completo, sin precios ni marcas de agua ajenas. Mantener el archivo ligero, idealmente menos de 400 KB. Guardar la procedencia o autorización junto a los originales.

La foto de base de datos tiene prioridad si ya existe. Cuando no hay archivo, se conserva el esquema identificado como ilustración; si una foto falla, también aparece el esquema. No renombrar una foto de otra variante como si fuera el modelo indicado.

Estos archivos forman parte del sitio: en producción hace falta desplegar la versión que los incluya. No existe todavía un formulario para subir fotos desde administración. Las imágenes de la base pueden seguir gestionándose mediante la integración existente de componentImages.
